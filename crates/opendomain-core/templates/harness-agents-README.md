# `agents/` — the generated agents (σ_i, prompt form)

`opendomain build` drops here one `*.md` per agent: system directive, tool
whitelist, I/O contract and criteria — the kit view, alongside
`AGENTS.md` (the shared execution contract) and `*.kit.json` (the
machine-readable projection). The file is the *verified artifact*, not an
opinion of the moment.
