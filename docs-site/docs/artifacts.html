Anatomy of a record

Each registry is a Markdown file cut into sections (one per record). The toml block carries machine-checked fields; the prose below is free and never parsed. Here is a complete record, annotated:

## REQ-012 — Look up an item's movement history

```toml
type = "FUNCTIONAL"        # kind of need
status = "DRAFT"           # progress state: work in progress
epistemic = "INFERRED"     # knowledge status: inferred, to confirm
confidence = "MEDIUM"      # confidence level
actor = ["ACT-002"]        # for whom: actor #2
derived-from = ["EVD-014"] # originating evidence — mandatory
rules = ["RULE-007"]       # the business rule concerned
```

**Statement**

The system SHALL let authorized users
look up an item's chronological movements.

The contract is simple: everything asserted in prose must have its counterpart in the TOML block. If the block says INFERRED, the prose may not speak as if it were certain. And if the TOML is malformed, the tool reports the line number instead of guessing.

Naming and linking

The prefix says what it is: REQ for a requirement, EVD for evidence, SRC for a source, RULE for a business rule, AC for an acceptance criterion, SPEC for a specification — 37 kinds in all, listed by od reference. Scope can be qualified (REQ-INVENTORY-014, AC-INVENTORY-014-01).

Links are declared by whoever depends on the other: you write REQ-004 derived-from RULE-001 on the requirement's record, never the reverse. Like citing sources at the bottom of a page, this makes walking back to the origin infallible.

A record's life, end to end

Take a bookstore trying to understand its returns:

  1. Source (SRC-003): interview with Mariam, the manager, notes and date.
  2. Finding (EVD-014, EXPLICIT): "30% of Monday returns come from picking errors".
  3. Requirement (REQ-012, INFERRED): look up movement history — the inference is recorded, not hidden.
  4. Confirmation (EVD-021): register exports confirm the Monday spike, and the record is promoted to EXPLICIT with its promotion journal.
  5. Specification and test (SPEC-008, AC-008-01): what will be observed, and how it will be verified.

At every step, gates verify: does the evidence cite a source? Does the requirement cite evidence? Does the test really cover the requirement marked "implemented"? Nothing passes by force — everything passes by evidence.
